# 0.11.1-alpha 验证范围

目标：Minecraft 1.21.1、NeoForge 21.1.169、AE2 19.2.19、GuideME 21.1.1、Java 21。范围为私有单人、本机 Agent Alpha。

## 撤回与移除

0.10.0-alpha 和 0.11.0-alpha 的 GitHub Release 记录、版本标签、两个 JAR 附件、关联的 13 个 Actions 构建附件及 15 次运行记录已删除。两个旧 JAR 下载地址均返回 HTTP 404。已下载或转存的文件无法召回。

0.11.1-alpha 删除远程 HTTP host、远程客户端、配对、远程设置页、独立启动器和内嵌 host JAR。新版本不读取旧连接凭据或共享配置，不自动恢复远程服务。详见 [SECURITY.md](../SECURITY.md)。

## 自动验证

Java 21 完成干净构建和最终构建，71 项 JUnit 测试全部通过，无失败、错误或跳过。移除的远程功能测试不再计入；新增本机迁移检查覆盖：

- 拒绝旧配对和共享操作，不写入配置或创建 host 身份。
- 拒绝旧远程目标及工单 ID，不将它们改派本机，也不重放旧 outbox。
- 旧远程 CPU 订单可以单独清理；新建的本机 CPU 订单不会误认为旧远程任务。该操作不控制或终止其他电脑上的旧进程。
- 完整归档的旧远程书籍图片仍能读取。
- 旧路由记录损坏时停止处理，不降级为本机执行。
- 三个新适配器继续经本机服务返回结果，并归档最终回答图片。

既有 Codex、DeepSeek Harness、Pi、OpenCode 2 协议、卡片、用量、步骤、问答、steering、成书分页和图片边界检查保持通过。没有调用真实模型。

`tools/verify_release.py` 检查版本、219 对中英文翻译、五份上游 MIT 原文字节、模组许可，以及远程代码、独立主机、启动入口和测试文件均不在发行 JAR 中。

## 游戏检查

中文 Linux 客户端检查 Agent 设置页：只保留本机 Agent 选择、路径、工作目录与检测；远程连接和共享按钮均不存在。官方 OpenCode 2 的本机程序检测通过，不发送任务。

检查时预置旧共享配置为开启状态。客户端启动、进入世界及打开设置后，旧配置端口均未监听。测试配置和原始日志不公开；检查完成后恢复开发环境配置。截图位于 `docs/screenshots/0.11.1-alpha-local-settings.png`。

## 限制

真实模型任务、Windows/macOS 游戏仍未验收。DeepSeek Harness 暂无问答、steering 或完整 Tokens；Pi 暂无游戏内问答；OpenCode 需要 2.x，仅支持简单问答表单。图片仍只接收 PNG/JPEG，不发送图片或下载外部图片网址。

本机不等于离线。模型 CLI 可联系其配置的模型服务。OpenCode 的官方本机接口仍由模组启动的进程监听 `127.0.0.1`，每次使用随机认证；它不提供本模组的跨机器控制服务。只读工具配置也不等于系统级隔离。
