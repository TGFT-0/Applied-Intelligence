# 0.11.1-alpha 发布审查

本版撤回远程能力，不尝试在未完成审计的链路上继续追加修复。受影响的两个公开发行附件和 13 份 CI 构建副本已删除，旧下载地址确认返回 404。

## 改动

- 删除远程连接客户端、HTTP host、配对、共享设置页和启动入口；发行包不包含独立 host。
- 保留四种本机 Agent、原版 AE2 合成列表、计时、CTX、Tokens、问答、steering、成书及图片归档。
- 旧共享配置不再启动服务，旧远程工单不改派本机。提供仅清理旧 CPU 订单的确认，不声称停止其他电脑上的旧进程。
- 已完整归档的旧书和图片继续可读。未取得的远程成果不再联网获取。
- 两版 README、使用指南、许可说明和安全撤回公告已同步。保留上游完整许可和参考记录。

## 检查

干净构建及最终构建成功。71 项 JUnit 测试通过，219 对翻译键一致。包检查明确拒绝远程类、配对页面、独立启动器、内嵌 host、测试代码和本机配置。

中文 Linux 客户端检查入口移除、本机选择及检测；开启状态的旧共享配置没有启动监听。新截图仅含测试游戏界面及临时路径。未调用真实模型。

公开范围不含运行日志、世界、凭据、旧 JAR 副本或工具安装目录。安全范围与用户需要执行的替换步骤见 [SECURITY.md](../SECURITY.md)。本次撤回不构成全面安全认证。
