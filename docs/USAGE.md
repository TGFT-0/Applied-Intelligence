# 使用指南

[返回首页](../README.md) · 中文 | [English](USAGE.en.md)

## 卡片与任务样板

在 AE2 样板编码终端右侧模式栏打开编辑页。将空白样板放入原版样板槽，为卡片命名后保存。

- **Skill 卡**保存常用指令，例如“先列出结论，再解释原因”。
- **任务样板**保存任务文本和所选 Skill 的快照。它安装在样板供应器里，由相邻的 Agent 装配器执行。

新增卡片消耗一个空白样板，编辑原卡不消耗。修改 Skill 卡不会改变已保存的任务样板，需要在任务编辑页重新选择并保存。

从编辑页齿轮打开 Agent 设置。点击顶部名称切换 Agent，填写 CLI 路径和工作目录，点击“保存并检测”。任务在该目录中以只读工具执行。执行电脑需要先在 CLI 中配置模型和登录；“CLI 已就绪”只表示检测到程序，不验证模型能否回答。

## 选择 Agent

| Agent | 接口与检查版本 | 补充指令 | 游戏内问答 | Tokens |
|---|---|---|---|---|
| Codex CLI | app-server，0.167.0-alpha.4 | 支持 | 支持 | CLI 上报时显示 |
| DeepSeek Harness | ACP v1，0.2.2-rc.3 | 暂无 | 暂无 | 暂无完整用量，显示 `—` |
| Pi | JSONL RPC，1.5.2 | 支持 | 暂无 | CLI 上报时显示 |
| OpenCode 2 | 本机 HTTP/SSE，2.2.7 | 支持 | 支持简单文本和单选表单 | CLI 上报时显示 |

这里的 DeepSeek Harness 是 `deepseek-ai/deepseek-harness` 的 `dsh` CLI；OpenCode 使用 `@opencode/cli` 的 **2.x**，不支持旧版 1.x API。可通过官方 npm 包安装：

```sh
npm install -g @deepseek-ai/dsh
npm install -g @earendil-works/pi-coding-agent
npm install -g @opencode/cli
```

默认程序名分别为 `dsh`、`pi`、`opencode`。Windows 的官方 npm 启动文件通过已知程序入口启动；自定义批处理启动器不受支持。Windows/macOS 尚未实机验收。

本机每次选择一个 Agent；已有本机任务保留提交时的 Agent。原有 Codex 设置无需迁移。协议测试与官方 CLI 连接检查已通过，真实模型执行尚未验收。

Pi 在受限模式下关闭扩展、MCP 与原生 Skills，只开放读文件、搜索和目录工具；游戏内 Skill 卡仍会随任务发送。DeepSeek 不把思考内容作为公开步骤；没有计划工具时，列表显示实际发生的工具操作。OpenCode 暂不接受隐藏、条件、数字或多选表单；这类表单会取消，不会代答。

## 阅读合成状态

| 显示项 | 含义 |
|---|---|
| 步骤 | Agent 提供的公开计划，最多 24 步。没有计划时显示已发生的工具操作类别 |
| 耗时 | CPU 的原版已用时间，不是预计剩余时间 |
| CTX | Agent 的上下文总容量，不是已用 Tokens，也不是实体 CPU 的字节数 |
| Tokens | 本次执行的输入加输出。缓存属于输入，不重复相加 |

本机设置可填写上下文容量，`0` 表示未知。下单页显示默认 Agent 的容量；实际任务报告可更新执行中的容量。

未知容量显示 `?`，未收到用量显示 `—`，真实零值显示 `0`。CLI 决定用量更新频率，可能只在结束时报告。同一窗口会保留上单用量，新开的空闲窗口不会显示其他历史任务。

AE2 仍按物品产出计算合成百分比。同一样板同时占用多个 CPU 时，步骤不能精确对应每个 CPU，补充指令和取消操作也会受限。

## 回答问题与补充指令

合成表出现“待回复”时，点击该条目选择建议或填写文本。全部题目填写后提交，原任务继续。返回列表不会发送空答案。普通文字问句不会自动创建回答表单。

等待回答时，Agent 的十分钟执行超时暂停，CPU 耗时继续计时。

执行中的“补充指令”输入框支持 Enter 换行，每条最多 4,000 字符。点击发送后，文本保留到收到确认；确认后显示“已追加”并清空。十秒后仍未确认时可以重试。明确拒收后可以继续编辑。

草稿在当前窗口内按任务保存，切换 CPU 或打开回答页会保留。关闭整个合成状态窗口会清除草稿。Agent 待回复时，需要先回答问题。回答和补充指令不会增加工具权限。

## 图片与成书

点击合成表中的“图片 · N 张”可打开查看器。它支持缩略图选择、前后切换、适应窗口、100%、滚轮缩放和拖动平移。

成果取入背包后自动转换为原版成书。文字保存在书中，图片在书末“图片附件”页通过链接打开。书页不内嵌图片。多份成果转换需要一个空背包格；背包满时保留成果物品。

图片限制如下：

| 项目 | 上限或范围 |
|---|---|
| 格式 | PNG、JPEG |
| 每单数量 | 8 张，重复内容去重 |
| 每张大小 | 源文件与转换后的 PNG 均不超过 2 MiB |
| 尺寸 | 每边不超过 4096 像素，总像素不超过 4,194,304 |
| 来源 | Agent 通过支持的协议上报的 PNG/JPEG、Codex 查看或生成的图片、MCP 图片数据、最终回答引用的工作目录内图片 |

模组不下载外部图片网址，也不跟随符号链接。无法读取或超限的源图片会跳过。图片重新编码为 PNG，去除源文件元数据。

本机收齐并校验图片后才交付成果。已归档图片保存在世界中，游戏重启后仍可查看。只复制书物品到另一个世界不会带走图片。

## 远程功能已撤回

0.11.1-alpha 仅支持本机 Agent。远程服务、配对、装配器远程绑定和独立 host 均已移除。旧共享配置不会自动启动服务，旧远程任务不会改派本机。

0.10.0-alpha 和 0.11.0-alpha 的发行附件已撤回。若你运行过旧独立 host，请关闭它，并替换游戏中的旧 JAR。替换模组不会关闭另一台电脑上已经运行的旧进程。

已有成书和完整归档的图片可以继续读取。未收齐的远程成果无法继续获取；失败订单可按下方方法退回纸张，并取消原 CPU 订单。保留旧配置和世界备份，但不要继续使用旧配对凭据。

## 取消、失败与断线

- 在本模组的合成状态页取消任务，会请求停止 Agent。收到任务取消确认后，才取消 CPU 订单。同样板占用多个 CPU 时，模组可能拒绝取消。
- 失败任务不生成成书。空手潜行右键装配器可退回纸张并重置，随后需要取消 CPU 中等待的旧订单。
- 其他模组直接取消 AE2 订单，不会自动停止已经提交的 CLI 任务。
- 连接中断时保留工单并重试，不创建替代任务。
- 退出世界会中断本机任务，重进不自动重跑。

## 存储与备份

| 内容 | 位置 |
|---|---|
| 本机配置 | 游戏实例的 `config/applied-intelligence-local.json` |
| 任务历史 | 世界目录的 `data/appliedintelligence/jobs.json` |
| 报告记录 | 世界目录的 `data/appliedintelligence_reports.dat` |
| 已归档图片 | 世界目录的 `data/appliedintelligence/report-images/` |

备份时保留整个世界。任务历史最多 100 条，未归档成果受到保留保护。成书保存文字，世界归档保存图片。
