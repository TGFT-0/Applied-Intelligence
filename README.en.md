Manage your Agent tasks right from your ME Terminal!
Place orders just like in vanilla AE2, track progress, and switch CPUs (Agents)!
Inspired by [T3Code](https://github.com/pingdotgg/t3code) and [T3-wow](https://github.com/ryanrhughes/t3code-wow).
This project was written entirely with GPT-6.1 Sol.


This mod supports Codex CLI, DeepSeek Harness, Pi, and OpenCode 2.
